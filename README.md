# Vortex Digital Agency Website

A premium, modern, stylish, and fully responsive website for **Vortex Digital**, a high-end performance digital marketing agency based in Indore, Madhya Pradesh, India. Built with a deep space-dark glassmorphic design system, optimized for speed, conversions, SEO, and interactive micro-interactions.

## Features

- **Premium Dark Aesthetics**: Styled with a continuous deep space-dark layout (`#08090f`) highlighted by neon cyan-to-blue and indigo-to-purple brand gradients, glassmorphism card surfaces (`backdrop-filter`), and premium soft shadows.
- **Sticky Glass Navbar**: Smooth-scrolling anchors with an active nav link indicator that highlights sections as you scroll, and a custom animated SVG spinner logo.
- **Hero Visual Section**: Showcases a modern SaaS-style analytics dashboard surrounded by floating CSS-animated widgets representing SEO, Conversion, and SMM trends.
- **Scroll-Triggered Animated Counters**: Interactive Intersection Observer counters that roll up numbers (100+ Projects, 50+ Clients, 3X ROI, 5+ Years) smoothly when scrolled into view.
- **6 Premium Service Cards**: SEO, Social Media, Google Ads, Meta Ads, Web Development, and Content Marketing, each equipped with Lucide icons, features list, and hover transitions.
- **Our Growth Process Timeline**: A horizontal/vertical timeline that fills its connecting line indicators step-by-step when the methodology section enters the viewport.
- **Interactive Portfolio Grid**: Premium layout cards with category filtering buttons (All, SEO, Social, Google Ads, Meta Ads, Web Design) that transition card states using smooth CSS scaling.
- **Case Study Visualizer**: A custom inline interactive SVG chart comparing a client's performance metrics "Before" and "After" Vortex campaigns.
- **Testimonials Carousel**: A touch-swipe friendly custom carousel featuring client reviews with dot indicators and next/prev arrow triggers.
- **CTA Dynamic Canvas Particles**: Features a dynamic canvas floating particle generator that renders drifting bubble elements inside the CTA banner background.
- **SEO & Schema Markup**: Integrates Open Graph metadata, semantic HTML structures (single H1, logical H2/H3 header trees), descriptive `alt` tags, and JSON-LD ProfessionalService schema.
- **Validated Contact Form**: Full client-side inputs checking with responsive error states, custom backdrop blur modal alert, and Canvas Confetti triggers on successful submissions.

## Technologies Used

- **HTML5 & CSS3** (Vanilla Flexbox/Grid, CSS Custom Properties, backdrop-filters, custom animations)
- **Vanilla JavaScript** (Intersection Observer API, Canvas API, touch/swipe listeners)
- **Lucide Icons** (CDN Integration)
- **Canvas Confetti** (CDN Integration)
- **Google Fonts** (Plus Jakarta Sans, Space Grotesk)

## Local Setup & Run

No build tools are required. You can launch the site immediately:
1. Clone or download the files.
2. Double-click `index.html` to open the website in any browser.
3. Run a local web server (e.g. Live Server in VS Code, `npx serve`, or python's `http.server`) to test full performance features.
